# 🌿 오늘의 감정 일기

하루의 감정과 생각을 차분히 기록하는 작은 온라인 일기장입니다.
감정을 고르고 마음을 적으면 Supabase에 저장되며, PC·스마트폰·다른 브라우저에서도 같은 기록을 확인할 수 있습니다.

> - GitHub Pages: 배포 후 링크를 추가해 주세요.

## 주요 기능

- 😊 기쁨, 😌 평온, 😢 슬픔, 😠 화남, 😰 불안 중 감정 선택
- 일기 작성 및 Supabase 저장
- 작성 일시 기준 최신순 목록 표시
- 전체 보기 및 감정별 필터
- 삭제 전 확인 대화상자
- 로딩, 저장 중, 빈 목록, 필터 결과 없음, 오류 상태 안내
- 모바일과 데스크톱에 대응하는 반응형 UI
- 종이 질감, 스티커, 테이프 장식 등을 활용한 아기자기한 다이어리 디자인

## 시작하기

### 1. 저장소 내려받기 및 의존성 설치

```bash
git clone https://github.com/heoyr123/26-w09-diary.git
cd 26-w09-diary
npm install
```

### 2. Supabase 환경 변수 설정

`.env.example`을 복사해 `.env.local`을 만들고 Supabase 프로젝트 값을 입력합니다.

```bash
cp .env.example .env.local
```

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxxxxxx
```

`.env.local`은 `.gitignore`에 포함되어 있으므로 커밋하지 않습니다.

### 3. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 엽니다.

## Supabase 데이터 구조

앱은 Supabase의 `diaries` 테이블을 사용합니다.

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| `id` | `bigint` | 자동 생성되는 일기 식별자 |
| `content` | `text` | 일기 본문 |
| `emotion` | `text` | `joy`, `calm`, `sad`, `angry`, `anxious` 중 하나 |
| `created_at` | `timestamptz` | 작성 시각, 데이터베이스 기본값 사용 |

테이블을 새로 만들 때 사용할 수 있는 기본 SQL 예시는 다음과 같습니다.

```sql
create table public.diaries (
  id bigint generated by default as identity primary key,
  content text not null,
  emotion text not null check (emotion in ('joy', 'calm', 'sad', 'angry', 'anxious')),
  created_at timestamptz not null default now()
);
```

이 프로젝트는 Realtime 웹소켓을 사용하지 않습니다. 일기를 작성하거나 삭제한 뒤 목록을 다시 조회하는 기본 CRUD 방식으로 동작합니다.

## 보안 및 운영 시 주의사항

- 프런트엔드에서 사용하는 `VITE_SUPABASE_PUBLISHABLE_KEY`는 공개 키입니다. 빌드 결과나 브라우저 개발자 도구에서 보일 수 있으므로 비밀 키처럼 취급하지 않습니다.
- 실제 데이터 보호는 Supabase의 Row Level Security(RLS) 정책이 담당합니다. 배포 전에는 반드시 RLS를 활성화하고, 사용자의 인증 상태에 맞는 `select`, `insert`, `delete` 정책을 설정하세요.
- 인증 없이 `using (true)` 정책을 사용하면 누구나 데이터를 조회하거나 수정할 수 있습니다. 개인 일기 서비스로 운영할 때는 적절한 로그인과 사용자별 소유권 정책을 추가해야 합니다.
- `.env.local`과 Supabase의 service role key는 GitHub에 올리지 않습니다. service role key는 브라우저 코드에서 절대 사용하지 않습니다.

## 현재 구현의 범위

현재 버전은 회원가입·로그인 없이 하나의 공유 일기 목록을 사용하는 기본 CRUD 학습용 앱입니다. 사용자별 비공개 일기, 수정 기능, 이미지 첨부, Realtime 동기화는 포함하지 않습니다.
